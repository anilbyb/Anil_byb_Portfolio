# Anıl Bayburtluoğlu | Design Technology Portfolio

I am an architect working across BIM, computational modelling and software development. This repository brings together selected project-specific scripts, visual programming definitions and supporting material from my technical work.

The current collection focuses on translating drawing and geometry data into BIM elements, automating modelling tasks, developing parametric facade workflows, and presenting selected game, VR and facility-management software work with public demo links.

## Repository scope


These files were developed and used on live AEC projects. They depend on model
templates, element types, custom parameters and input data that are not published
here, so they are shared as technical samples rather than runnable tools.

Game and software pages use selected screenshots and externally hosted videos,
since full project sources and builds are not part of this repository.
