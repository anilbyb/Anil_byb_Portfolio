# Architectural Revit Modelling

This collection contains one documented workflow: [wall modelling from drawing data](Model_Walls_From_DWG/README.md).

It combines Rhino and Grasshopper data preparation with a Revit Python wall-creation script and a Dynamo graph intended for wall/beam processing. The workflow page lists the included files, required inputs and limitations.
