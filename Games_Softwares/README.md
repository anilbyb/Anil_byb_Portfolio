## Scope Notes

- Large videos remain hosted externally rather than being committed to the repository.
- One lightweight thumbnail per project is included locally; the remaining supplied screenshots are linked through the project Drive folders.
- Source descriptions are based on the project notes and media supplied in the Drive showcase folder.
- The projects were not rebuilt, run or independently tested as part of this documentation update.
- Screenshots and videos are used as presentation evidence, not as proof of current build compatibility.
