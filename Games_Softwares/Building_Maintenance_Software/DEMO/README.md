# Facility Management Demo Notes

This folder is used for presentation notes related to the facility-management software demo.

The original demo combined exported Revit geometry and parameter data with a Unity-based viewer. The available showcase material demonstrates the intended interface and workflow rather than a runnable application package.

## Demonstrated Capabilities

- Viewing a facility model in different visual modes
- Inspecting asset and room-related information
- Using maintenance and warranty data for colour-coded model feedback
- Creating maintenance or replacement tasks from selected building elements
